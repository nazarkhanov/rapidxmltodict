## rapidxmltodict 0.1.0: first public release

A C++/CPython XML-to-dictionary parser powered by RapidXML, with the familiar
`xmltodict` API and output format. Python dictionaries, lists and strings are
built directly, without an intermediate JSON conversion.

### Highlights

- Accelerated parsing for common UTF-8 `str`/`bytes` inputs with default options.
- `xmltodict`-compatible attributes, repeated elements, text/CDATA and Unicode handling.
- PEP 561 type hints and editor autocomplete for `parse` and `unparse`.
- Prebuilt wheels for CPython 3.9–3.14 on Linux x86-64 (manylinux), Windows x64,
  and macOS Intel/Apple Silicon, plus a source distribution.

### Compatibility and safety

Advanced options, streaming inputs, DTDs, non-UTF-8 encodings and other unsupported
native cases fall back to `xmltodict`. `unparse` is re-exported from `xmltodict`.
The native path validates XML with Expat; external entities are disabled by
default. Native acceleration covers a defined subset of the `xmltodict` API.
Applications should still enforce resource limits for untrusted input.

### Performance

Recorded CPython 3.12/Linux synthetic catalog benchmarks measured **4.47–5.26×
faster end-to-end parsing** than `xmltodict` 0.14.2. Results depend on the workload
and machine; fallback cases can be slower, and lower memory use is not guaranteed.
See the [benchmark methodology and results](https://github.com/nazarkhanov/rapidxmltodict/blob/v0.1.0/benchmarks/README.md)
and [compatibility and security notes](https://github.com/nazarkhanov/rapidxmltodict/blob/v0.1.0/README.md).
